## 5分日次レビュー・テンプレートジェネレータ

毎日の振り返り（Win・学び・優先・感謝）を記録し、過去30日からパターンを発見するリフレクションツール。

### 機能
- 本日の振り返りフォーム: Win×3・学び・明日の最優先・感謝
- localStorage に日付キーで保存・ページリロード後も復元
- 過去30日のリスト表示（個別削除対応）
- 頻出ワード分析: Win/学び/優先/感謝の各フィールドから繰り返しキーワードをタグ表示
- Markdown エクスポート（月次サマリー .md ダウンロード）

### 技術
- 静的SPA（index.html単体）
- Tailwind CSS CDN
- localStorage（日付キー JSON 保存）
- XSS対策: htmlEscape() による全出力エスケープ
